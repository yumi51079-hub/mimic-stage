# MIMIC STAGE

ChatGPTへのログインやCloudflareの専用環境を使わないオンライン声まねゲーム。1〜5人が最初に自分の音源を選択し、全員分のお題で同時に声まねして合計点を競います。

Node.js 24で `npm start` を実行するとポート3000で起動します。外部公開にはHTTPS対応のホスティングが必要です。DockerfileとRender用の設定を同梱しています。Renderではこのフォルダーをサービスのルートに設定します。

マイクを使うため、友達にはHTTPSの公開URLを送ってください。ルームコードで参加できます。アカウントやChatGPTの接続は不要です。

データは `DATA_DIR`（既定はdata）に保存します。ホストの退出でそのルームの音声を削除します。期限切れデータは10分間隔で削除します。永続ディスクがない公開先では再起動時にデータが消えることがあるため、ルームを作り直してください。Render無料枠では休止・再起動が起こる場合があります。

音源は選んだ区間だけを配信します。録音共有は各プレイヤーが選択できます。採点は端末側の音声特徴比較による目安です。

## 内蔵ミーム音声100個

実在する音声100個を検索・カテゴリ・試聴から選べます。「これにする」でお題を自動送信します。ランダム選択も可能です。自分のMP3も使えます。

ローカル起動前は `npm run samples` で音声を取得してください。Dockerビルドでは自動取得し、全100ファイルのSHA-256とサイズを検証します。素材は生成音声ではありません。出典は `SAMPLE_SOURCES.md` と各カードに掲載しています。

「1人で遊ぶ」からソロ練習を開始できます。オンラインルームも1人で開始でき、準備中に友達を招待すると最大5人で対戦できます。
